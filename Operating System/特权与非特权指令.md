## 特权指令与非特权指令

## 一、基本概念

### 特权指令
- **定义**：只能在操作系统内核态执行的指令  不允许用户直接使用的指令
- **特点**：涉及系统关键资源的操作
- **执行状态**：核心态（管态）

### 非特权指令
- **定义**：在用户态和内核态都能执行的指令  用户直接能使用的指令
- **特点**：不会影响系统安全性和稳定性
- **执行状态**：用户态（目态）和核心态

## 二、特权指令示例

### 硬件相关操作
- **I/O 指令**：in/out 等端口操作
- **内存保护设置**：页表/段表寄存器加载
- **时钟设置**：修改系统时钟
- **中断屏蔽**：开/关中断指令

### 系统控制指令
- **清内存**：清除整个内存空间
- **设置定时器**：修改时钟中断频率
- **停机指令**：halt 停止系统运行
- **切换处理器状态**：用户态↔内核态转换

## 三、非特权指令示例

### 运算指令
- **算术运算**：add、sub、mul、div
- **逻辑运算**：and、or、not、xor
- **移位运算**：shl、shr

### 数据传送
- **寄存器操作**：mov、push、pop
- **内存访问**：load、store（在权限范围内）

### 流程控制
- **跳转指令**：jmp、call、ret
- **条件分支**：je、jne、jg 等

## 四、处理器状态与指令执行

### 状态标识
- **用户态（目态）**：PSW 中特权位为 0
- **核心态（管态）**：PSW 中特权位为 1

### 执行控制
```c
if (当前状态 == 用户态 && 指令类型 == 特权指令) {
    产生异常/陷入(trap)；
    切换到内核态；
    由操作系统处理；
} else {
    正常执行指令；
}
```

## 五、常考考点

1. **指令分类判断**
   - 给定指令列表，区分特权/非特权指令

2. **状态转换机制**
   - 用户态→内核态：通过中断/异常/系统调用
   - 内核态→用户态：设置PSW后执行中断返回

3. **系统调用过程**
   - 用户程序执行访管指令（陷入指令）
   - 产生软中断，切换到内核态
   - 操作系统执行相应特权指令
   - 返回用户态

4. **设计原则**
   - 特权指令完整性：关键操作必须特权化
   - 安全性：用户程序不能直接执行特权指令
   - 效率性：状态切换需要开销

## 六、重要结论
- **特权指令是操作系统实现资源管理的硬件基础**
- **用户程序通过系统调用间接使用特权指令功能**
- **处理器状态位是实现指令权限控制的硬件机制**
