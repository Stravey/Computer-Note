# B树

## 一、B树定义

m阶B树是所有结点的平衡因子均等于0的m路平衡查找树。

一棵m阶B树或为空树，或为满足如下特征的m叉树：

（1）树中结点至多有m棵子树，即至多有m-1个关键字；

（2）若根结点不是叶结点，则至少有两棵子树，即至少有一个关键字；

B-tree 即 B树，B 即 Balanced，平衡的意思。

B树 是一颗多路平衡查找树。

### 1.1 B树的特性

一棵m阶B树（m>=3），或是空树，或是具有如下几个特征的树：

1. 如果是根结点，则 2 <= 根结点的**孩子数** <= m；（根结点至少包含一个**关键字**）。

2. 非叶子节点（除根结点和叶子结点外），ceil(m/2) <= 其包含的**孩子数** <= m，其包含的**关键字数** = 它的孩子数-1。【注：ceil(x)：向上取整】

3. 所有叶子结点都出现在同一层，ceil(m/2)-1 <= 结点包含的 **关键字数** <= m - 1；

4. 每个结点中的 **关键字** 从小到大排列，并且非叶子结点的k-1个 **关键字** ，正好是它k个孩子包含的关键字的值域分划。

   【即：父结点中的第i个关键字（如果存在） < 第i个孩子中的所有关键字 < 父结点中的第i+1个关键字（如果存在）】

### 1.2 B树的高度

对于一个m（m>=3）阶B树，假设关键字总数目为n，高度为h：

1. 根结点至少有2个孩子（根结点至少有一个关键字），因此第二层至少有两个结点；

2. 除根和叶子结点外，其他结点至少有t=ceil(m/2)个孩子（取最小时，除根结点外，其他结点包含的关键字个数为t-1）。因此，第三层至少有2t个结点（第二层每个结点包含的关键字个数为t-1），第四层至少有 `2t^2` 个结点（第三层每个结点包含的关键字个数为t-1），……，第h-1层至少有`2t^(h-3)`个结点（第h-2层每个结点包含的关键字个数为t-1）；

3. 将所有结点包含的关键字相加：

   ![在这里插入图片描述](https://i-blog.csdnimg.cn/blog_migrate/b9480b4eb9af7aa4bdfbc71f8ed6bea8.jpeg)

**由此可知：**

1. 在B树上增删改查的磁盘IO次数为为O(logtn)，CPU时间为O(mlogtn)。
2. 在关键字总数目不变的情况下，结点包含的关键字越多，B树的高度越小。这也是为什么SQL Server中应尽量以窄键建立聚集索引。因为键越小，结点可容纳的关键字越多，B树的高度越小，从而提升了查询性能。

### 1.3 性能分析

1. n个关键字的平衡二叉排序的高度（lgn）比B树的高度约大lgt倍。

2. 若作为在内存中使用的表结构，B树不一定比平衡二叉树好，尤其当m较大时更是如此。
   这是因为B树增删改查的CPU时间：O(mlogtn)=0(lgn·(m/lgt))。

   而m/lgt>1，因此当m较大时，O(mlogtn)比平衡二叉排序树的CPU时间O(lgn)大得多。故，若B树仅作为在内存中使用，则应取较小的m。（通常取最小值m=3，此时B树每个内部结点孩子数目可为2或3，这种3阶的B-树称为2-3树）。

### 1.4 补充说明

1. B树的 **阶数** 是指 树中 的 **最多子节点个数**。比如，2-3树的阶是3，2-3-4树的阶是4；
2. B-树的搜索，从根结点开始，对结点内的关键字（有序）序列进行二分查找，如果命中则结束，否则进入查询关键字所属范围的儿子结点；重复，直到所对应的儿子指针为空，或已经是叶子结点；
3. 关键字集合分布在整棵树中, 即叶子节点和非叶子节点都存放数据；
4. 搜索有可能在非叶子结点结束；
5. 其搜索性能等价于在关键字全集内做一次二分查找；

### 1.5 B树、B-树 、B-tree、B tree的区别

1. B树： B树 的原英文名称为 B-tree 。
2. B-树：国内很多人喜欢把 B-tree译作 B-树 。其实，这是个非常不好的直译，很容易让人产生误解。 初学者可能误认为 B-树 是一种树，而 B树 又是另一种树。 而事实上是 它们都是指的同一种 “树” 。
3. B tree ： 就是 B树 。

总结： B树 == B-树 == B-tree == B tree 。

## 二、B树的插入操作

插入操作是指插入一条记录，即（key, value）的键值对。如果B树中已存在需要插入的键值对，则用需要插入的value替换旧的value。若B树不存在这个key,则一定是在叶子结点中进行插入操作。

1）根据要插入的key的值，找到叶子结点并插入。

2）判断当前结点key的个数是否小于等于m-1，若满足则结束，否则进行第3步。

3）以结点中间的key为中心分裂成左右两部分，然后将这个中间的key插入到父结点中，这个key的左子树指向分裂后的左半部分，这个key的右子支指向分裂后的右半部分，然后将当前结点指向父结点，继续进行第3步。（ **当阶数m为偶数时，需要分裂时就不存在排序恰好在中间的key，那么我们选择中间位置的前一个key或中间位置的后一个key为中心进行分裂即可。** ）

```c++
#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

// B树节点类
class BTreeNode {
public:
    vector<int> keys;          // 关键字数组
    vector<BTreeNode*> children; // 孩子指针数组
    int keyNumber;              // 当前关键字数量
    bool leaf;                  // 是否为叶子节点
    int t;                      // 最小度数

    BTreeNode(int _t, bool _leaf) : t(_t), leaf(_leaf), keyNumber(0) {
        keys.resize(2 * t - 1);
        children.resize(2 * t);
    }

    // 查找key是否存在当前节点
    int findKey(int key) {
        int idx = 0;
        while (idx < keyNumber && keys[idx] < key) {
            ++idx;
        }
        return idx;
    }

    // 在指定位置插入key
    void insertKey(int key, int index) {
        for (int i = keyNumber; i > index; --i) {
            keys[i] = keys[i - 1];
        }
        keys[index] = key;
        keyNumber++;
    }

    // 在指定位置插入孩子节点
    void insertChild(BTreeNode* child, int index) {
        for (int i = keyNumber + 1; i > index; --i) {
            children[i] = children[i - 1];
        }
        children[index] = child;
    }

    // 删除指定位置的key
    int removeKey(int index) {
        int removedKey = keys[index];
        for (int i = index; i < keyNumber - 1; ++i) {
            keys[i] = keys[i + 1];
        }
        keyNumber--;
        return removedKey;
    }

    // 删除指定位置的孩子
    BTreeNode* removeChild(int index) {
        BTreeNode* removedChild = children[index];
        for (int i = index; i < keyNumber; ++i) {
            children[i] = children[i + 1];
        }
        children[keyNumber] = nullptr;
        return removedChild;
    }

    // 获取左兄弟
    BTreeNode* getLeftSibling(int index) {
        return index > 0 ? children[index - 1] : nullptr;
    }

    // 获取右兄弟
    BTreeNode* getRightSibling(int index) {
        return index < keyNumber ? children[index + 1] : nullptr;
    }

    // 将当前节点的内容合并到目标节点
    void mergeTo(BTreeNode* target) {
        int start = target->keyNumber;
        // 复制keys
        for (int i = 0; i < keyNumber; ++i) {
            target->keys[start + i] = keys[i];
        }
        // 如果不是叶子节点，复制children
        if (!leaf) {
            for (int i = 0; i <= keyNumber; ++i) {
                target->children[start + i] = children[i];
            }
        }
        target->keyNumber += keyNumber;
    }
};

// B树类
class BTree {
private:
    BTreeNode* root;
    int t;  // 最小度数
    const int MIN_KEY_NUMBER;
    const int MAX_KEY_NUMBER;

public:
    BTree(int _t) : t(_t), MIN_KEY_NUMBER(t - 1), MAX_KEY_NUMBER(2 * t - 1) {
        root = new BTreeNode(t, true);
    }

    // 查找key是否存在
    bool contains(int key) {
        return search(root, key) != nullptr;
    }

    // 递归查找
    BTreeNode* search(BTreeNode* node, int key) {
        int i = 0;
        while (i < node->keyNumber && key > node->keys[i]) {
            i++;
        }
        if (i < node->keyNumber && key == node->keys[i]) {
            return node;
        }
        if (node->leaf) {
            return nullptr;
        }
        return search(node->children[i], key);
    }

    // 插入key
    void insert(int key) {
        if (root->keyNumber == MAX_KEY_NUMBER) {
            BTreeNode* newRoot = new BTreeNode(t, false);
            newRoot->children[0] = root;
            splitChild(newRoot, 0);
            root = newRoot;
        }
        insertNonFull(root, key);
    }

private:
    // 向非满节点插入key
    void insertNonFull(BTreeNode* node, int key) {
        int i = node->keyNumber - 1;
        if (node->leaf) {
            while (i >= 0 && key < node->keys[i]) {
                node->keys[i + 1] = node->keys[i];
                i--;
            }
            node->keys[i + 1] = key;
            node->keyNumber++;
        } else {
            while (i >= 0 && key < node->keys[i]) {
                i--;
            }
            i++;
            if (node->children[i]->keyNumber == MAX_KEY_NUMBER) {
                splitChild(node, i);
                if (key > node->keys[i]) {
                    i++;
                }
            }
            insertNonFull(node->children[i], key);
        }
    }

    // 分裂子节点
    void splitChild(BTreeNode* parent, int index) {
        BTreeNode* child = parent->children[index];
        BTreeNode* newChild = new BTreeNode(t, child->leaf);
        
        // 移动后半部分key到新节点
        for (int j = 0; j < t - 1; ++j) {
            newChild->keys[j] = child->keys[j + t];
        }
        newChild->keyNumber = t - 1;
        
        // 如果不是叶子节点，移动后半部分children
        if (!child->leaf) {
            for (int j = 0; j < t; ++j) {
                newChild->children[j] = child->children[j + t];
            }
        }
        child->keyNumber = t - 1;
        
        // 将中间key提升到父节点
        parent->insertKey(child->keys[t - 1], index);
        
        // 将新节点插入到父节点的children中
        parent->insertChild(newChild, index + 1);
    }

public:
    // 删除key
    void remove(int key) {
        removeKey(root, key);
        
        // 如果根节点没有key但有孩子，则降低树高
        if (root->keyNumber == 0 && !root->leaf) {
            BTreeNode* oldRoot = root;
            root = root->children[0];
            delete oldRoot;
        }
    }

private:
    void removeKey(BTreeNode* node, int key) {
        int idx = node->findKey(key);
        
        if (idx < node->keyNumber && node->keys[idx] == key) {
            // 找到key
            if (node->leaf) {
                // 情况1: 叶子节点直接删除
                node->removeKey(idx);
            } else {
                // 情况2: 非叶子节点
                BTreeNode* predecessor = getPredecessor(node, idx);
                if (predecessor->keyNumber > MIN_KEY_NUMBER) {
                    // 情况2a: 前驱节点有足够key
                    int predKey = predecessor->keys[predecessor->keyNumber - 1];
                    node->keys[idx] = predKey;
                    removeKey(predecessor, predKey);
                } else {
                    BTreeNode* successor = getSuccessor(node, idx);
                    if (successor->keyNumber > MIN_KEY_NUMBER) {
                        // 情况2b: 后继节点有足够key
                        int succKey = successor->keys[0];
                        node->keys[idx] = succKey;
                        removeKey(successor, succKey);
                    } else {
                        // 情况2c: 合并前驱和当前key
                        mergeNodes(node, idx, predecessor, successor);
                        removeKey(predecessor, key);
                    }
                }
            }
        } else {
            // 没有在当前节点找到key
            if (node->leaf) {
                return; // key不存在
            }
            
            bool isLastChild = (idx == node->keyNumber);
            BTreeNode* child = node->children[idx];
            
            if (child->keyNumber == MIN_KEY_NUMBER) {
                // 需要调整以保证child有足够key
                fillChild(node, idx);
            }
            
            if (isLastChild && idx > node->keyNumber) {
                removeKey(node->children[idx - 1], key);
            } else {
                removeKey(node->children[idx], key);
            }
        }
    }

    // 获取前驱节点
    BTreeNode* getPredecessor(BTreeNode* node, int idx) {
        BTreeNode* curr = node->children[idx];
        while (!curr->leaf) {
            curr = curr->children[curr->keyNumber];
        }
        return curr;
    }

    // 获取后继节点
    BTreeNode* getSuccessor(BTreeNode* node, int idx) {
        BTreeNode* curr = node->children[idx + 1];
        while (!curr->leaf) {
            curr = curr->children[0];
        }
        return curr;
    }

    // 合并两个节点
    void mergeNodes(BTreeNode* parent, int idx, BTreeNode* left, BTreeNode* right) {
        // 将父节点的key下移到左节点
        left->keys[left->keyNumber] = parent->removeKey(idx);
        left->keyNumber++;
        
        // 将右节点的内容合并到左节点
        right->mergeTo(left);
        
        // 移除右节点指针
        parent->removeChild(idx + 1);
        delete right;
    }

    // 填充key不足的子节点
    void fillChild(BTreeNode* parent, int idx) {
        // 尝试从左兄弟借key
        if (idx != 0 && parent->children[idx - 1]->keyNumber > MIN_KEY_NUMBER) {
            borrowFromLeft(parent, idx);
        }
        // 尝试从右兄弟借key
        else if (idx != parent->keyNumber && parent->children[idx + 1]->keyNumber > MIN_KEY_NUMBER) {
            borrowFromRight(parent, idx);
        }
        // 需要合并
        else {
            if (idx != parent->keyNumber) {
                mergeNodes(parent, idx, parent->children[idx], parent->children[idx + 1]);
            } else {
                mergeNodes(parent, idx - 1, parent->children[idx - 1], parent->children[idx]);
            }
        }
    }

    // 从左兄弟借key
    void borrowFromLeft(BTreeNode* parent, int idx) {
        BTreeNode* child = parent->children[idx];
        BTreeNode* leftSibling = parent->children[idx - 1];
        
        // 将父节点的key下移到child
        child->insertKey(parent->keys[idx - 1], 0);
        
        // 将左兄弟的最后一个孩子移到child
        if (!child->leaf) {
            child->insertChild(leftSibling->removeChild(leftSibling->keyNumber), 0);
        }
        
        // 将左兄弟的最后一个key上移到父节点
        parent->keys[idx - 1] = leftSibling->removeKey(leftSibling->keyNumber - 1);
    }

    // 从右兄弟借key
    void borrowFromRight(BTreeNode* parent, int idx) {
        BTreeNode* child = parent->children[idx];
        BTreeNode* rightSibling = parent->children[idx + 1];
        
        // 将父节点的key下移到child
        child->keys[child->keyNumber] = parent->keys[idx];
        child->keyNumber++;
        
        // 将右兄弟的第一个孩子移到child
        if (!child->leaf) {
            child->children[child->keyNumber] = rightSibling->removeChild(0);
        }
        
        // 将右兄弟的第一个key上移到父节点
        parent->keys[idx] = rightSibling->removeKey(0);
    }

public:
    // 打印B树（辅助函数）
    void print() {
        if (root != nullptr) {
            printNode(root, 0);
        }
    }

private:
    void printNode(BTreeNode* node, int level) {
        cout << "Level " << level << ": ";
        for (int i = 0; i < node->keyNumber; ++i) {
            cout << node->keys[i] << " ";
        }
        cout << endl;
        
        if (!node->leaf) {
            for (int i = 0; i <= node->keyNumber; ++i) {
                if (node->children[i] != nullptr) {
                    printNode(node->children[i], level + 1);
                }
            }
        }
    }
};

int main() {
    BTree t(3); // 最小度数=3
    
    // 测试插入
    t.insert(10);
    t.insert(20);
    t.insert(5);
    t.insert(6);
    t.insert(12);
    t.insert(30);
    t.insert(7);
    t.insert(17);
    
    cout << "B树结构:" << endl;
    t.print();
    
    // 测试查找
    cout << "\n查找6: " << (t.contains(6) ? "存在" : "不存在") << endl;
    cout << "查找15: " << (t.contains(15) ? "存在" : "不存在") << endl;
    
    // 测试删除
    t.remove(6);
    t.remove(13);
    t.remove(7);
    
    cout << "\n删除后的B树结构:" << endl;
    t.print();
    
    return 0;
}
```
